# 入境游客服务接力

衔接入境游客从行前咨询到抵达游览和求助的多方服务。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括入境游客、旅行服务商、支付与交通服务方、文旅行业管理人员。

资料所依据的领域事实如下：

- 入境旅游便利化讨论市场营销、数字创新和跨境支付
- 参与者来自政府、行业协会、金融机构和文旅企业
- 行业希望推动服务标准化、数字化和国际化

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
